# Ablation program: which JEPA components actually matter?

Designed 2026-07-08 from the two findings so far: (a) latent arms trail MTP on
planning; (b) the shallow same-pass latent task saturates in the first ~20% of
training, and the one variant that keeps it hard (EMA + deep target) is the
best latent arm. Reference: "When Does LeJEPA Learn a World Model?"
(arXiv 2605.26379) — alignment + explicit Gaussianity regularization (SIGReg);
batch-statistic regularizers (SIGReg, VICReg) scale where InfoNCE degrades.

## Dataset policy (cheapest task that can answer the question)

| bed | cost/run | role |
|---|---|---|
| **maze** (6×6) | ~4 min | primary ablation bed — only Tier-0 task where methods separate (NTP .696 → MTP .821) |
| star graph | ~3 min | spot-check only: does the overall winner budge the at-chance planning failure? (cannot *rank* methods — everything is at chance) |
| TinyStories | ~65 min | transfer check for the 1–2 winning configs only |

All maze runs: 4000 steps, batch 128, 6L/256d, 3 seeds, NTP weight 1.0 +
one latent loss at weight 0.5 — identical to the existing passes, so every
new cell is directly comparable to `maze_*` and `maze2_*` results.

**Anchors (already run):** ntp .696±.043 · mtp(k=4) .821±.014 ·
pooled k8 shallow same-pass .712±.009 · pooled k8 EMA tgt4 .744±.020 ·
pooled k16 shallow .714±.021 · pooled k8 answer-only .736±.040 ·
pyramid λ×2 .720±.024.

## Q1 + Q2 — EMA vs same-pass, isolated from target depth

Full 2×4 factorial (teacher × target layer), pooled k=8, src=-1:

| | tgt=1 | tgt=2 | tgt=4 (⅔) | tgt=6 (top) |
|---|---|---|---|---|
| same-pass stop-grad | **done** (.712) | A1 | A2 | A3 |
| EMA (0.999) | A4 | A5 | **done** (.744) | A6 |

6 new configs. Reading: EMA effect = column-wise pairs; depth effect =
row-wise. If EMA-tgt1 ≈ same-pass-tgt1 but EMA-tgt4 ≫ same-pass-tgt4,
the win is the *combination* (deep targets need a stable teacher).

## Q3 — source depth (the D2′ hypothesis)

Pooled k=8, EMA tgt=4 (current best teacher), vary where the predictor taps
the trunk: src ∈ {2, **4 (⅔ — the original idea: src=tgt=⅔, EMA target)**, 6=done}.
2 new configs (B1, B2). If src=4 matches src=6, the planning signal can move
mid-depth — unlocking the D2′ architecture where the top layers stay purely
lexical.

## Q4 — task hardness: how much future, how many latents

User hypothesis: latent regression is "too easy" — needs far more future than
MTP to carry equivalent training signal. With EMA tgt=4, src=-1:

- pooled window k ∈ {4, C1 · 8 = done · 16, C2 · 32, C3}
- per-token M ∈ {8, C4 · 16, C5} (existing pertoken M=4 was shallow same-pass;
  these get the EMA-deep teacher so hardness is the only change vs C-row)
- **MTP k=8 control (C6)** — matched-horizon discrete control, so
  "JEPA needs more horizon than MTP" is tested against MTP at the same
  horizon, not only k=4.

## Q5 — chunk-to-chunk prediction + attention pooling

Pool the *source* too: the trailing c tokens' hiddens predict the pooled next
k. c ∈ {4 (D1), 8 (D2)}, k=8, EMA tgt=4. (Requires the `src_pool` code added
for this study.)

Pooling operator: mean vs **attention pooling** (D3: target window only,
D4: both sides with c=8). A linear scorer produces softmax weights over the
window; the scorer trains through the loss while pooled *values* stay
stop-grad. Known risk to watch: the scorer may collapse onto the
easiest-to-predict token (e.g., the nearest), silently shrinking the horizon —
compare its result against k=1-ish behavior before trusting a win.

## Q6 — objective / anti-collapse family (LeJEPA-informed)

On the reference arm (pooled k=8, EMA tgt=4, src=-1), factor the loss into
alignment + distributional regularizer on the predictor outputs:

| config | alignment | regularizer |
|---|---|---|
| done | cosine | none (stop-grad+asym predictor only) |
| E1 | L2 | none |
| E2 | L2 | **SIGReg** (random 1-D projections, CF match to N(0,1)) |
| E3 | L2 | **VICReg** (variance hinge + covariance penalty) |
| E4 | InfoNCE (in-batch negatives, τ=0.1) | none |

SIGReg implementation: K=32 fresh random unit directions per step; for each,
match the empirical characteristic function of the projected predictions to
the standard Gaussian's on a fixed frequency grid (Epps–Pulley-style).
Expected per LeJEPA: E2 ≥ E3 ≥ E4 in stability/scaling; any of them beating
plain cosine says our stop-grad-only anti-collapse was leaving signal on the
table.

## Budget

`runs/abl_<cell>_seed<s>`; configs generated by
`scripts/gen_ablation_configs.py`, executed by `scripts/run_ablation.sh`,
aggregated by `scripts/collect_results.py`.

**TinyStories seed suite truncated by decision (2026-07-08):** stop after
`mtp_seed2` — NTP and MTP get full 3-seed CIs (the controls worth
pinning down); jepa/nitp/pertoken/pyramid stay at 1 seed because we have not
yet found a good JEPA configuration, and 4×2 more hour-long runs of
known-suboptimal configs is compute better spent on this ablation. Tier-1
seeds for the JEPA arms resume once the ablation picks a winner.
